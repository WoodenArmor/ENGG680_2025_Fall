## 2. Assignment Overview

This lab assignment focuses on fundamental concepts in estimation and machine learning, including implementing the Least Square Estimation (LSE) for non-linear problems, understanding Gradient Descent, and applying various machine learning models to real-world datasets.

The main tasks are:
<br>
Non-linear Estimation (LSE & Gradient Descent): Implementing Single Point Positioning (SPP) using LSE and exploring the principles of Gradient Descent.

Student Depression Prediction: Analyzing and predicting student depression levels using Logistic Regression.

Handwritten Digit Classification: Comparing the performance of a Multi-Layer Perceptron (MLP) and a Convolutional Neural Network (CNN) for classifying the MNIST handwritten digit dataset.
