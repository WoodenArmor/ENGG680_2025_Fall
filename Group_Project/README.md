## 2. Group Project Overview

The objective of this group project is explainable Machine Learning for Concrete Compressive Strength Prediction. 
<br>
Concrete Compressive Strength (CCS) is a critical factor in ensuring the safety and performance of civil infrastructure. Traditional testing methods are destructive, time-consuming, and costly. While Machine Learning (ML) offers a fast and non-destructive alternative, complex models often suffer from a "black box" nature, lacking transparency in engineering decision-making.

This project develops an interpretable ML framework to accurately predict CCS. By integrating **SHAP (SHapley Additive exPlanations)** analysis, we not only achieve high predictive accuracy but also quantify the contribution of each mix-design parameter (e.g., cement, water, curing age).
